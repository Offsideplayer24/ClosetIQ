## Project Description

ClosetIQ is a planned AI-assisted mobile application focused on travel packing and wardrobe organization. The project explores the challenges people face when deciding what to pack for different trips, such as forgetting essential items, bringing clothing that does not suit the weather, activities, or dress code, and buying items they already own.

## Phase 3 demo

Download [ClosetIQ.html](https://github.com/Offsideplayer24/ClosetIQ/raw/refs/heads/main/demo/ClosetIQ.html) and open it in a browser. The mobile-first demo runs offline with a sample New York wedding itinerary, weather forecast, and photo recognition results.

Try adding the rehearsal dinner to the trip. A dress shirt and the same trousers worn on travel days cover dinner, while the packing plan still flags the formal wedding outfit.

Next, we plan to test whether travelers understand which items they can reuse and what they still need. Later iterations can support more trip types and add AI-assisted itinerary planning and photo recognition while keeping clothing choices editable.
